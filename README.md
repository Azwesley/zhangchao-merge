# 合成张超 · 三国合成志

手机和电脑都能玩的原创三国主题合成小游戏。移动瞄准，松手投放；相同英雄碰撞后升级，最终合成最大的「张超」。

人物顺序：小兵 → 貂蝉 → 张飞 → 赵云 → 马超 → 关羽 → 刘备 → 曹操 → 诸葛亮 → 吕布 → 张超。

- 原创 SVG 人物、物理碰撞、连锁反馈、可选音效。
- 每局一次「借东风」移走最小的三位英雄。
- 浏览器本地最高分；不需要账号，不收集个人数据。
- 「邀友来战」复制带相同人物序列与分数目标的挑战网址。
- 键盘支持：棋盘获得焦点后，左右方向键移动，空格或回车投放。
- 停留在弹窗或切到后台时，游戏暂停。

## 本地运行

在此目录运行 `python3 -m http.server 4178`，打开 `http://localhost:4178`。

游戏采用本地附带的 Matter.js 0.20.0（MIT，见 vendor/LICENSE），无在线字体、素材或 CDN 运行依赖。其余画面和代码为本项目制作。
